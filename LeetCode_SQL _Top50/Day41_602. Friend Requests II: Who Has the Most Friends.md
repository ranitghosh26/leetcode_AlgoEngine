## 📝 Problem Summary

Given the `RequestAccepted` table, every accepted friend request creates a friendship between two users.

Each accepted request contributes:

- **1 friend** to the requester.
- **1 friend** to the accepter.

Find the user who has the **maximum number of friends** and return:

- `id` → User ID
- `num` → Number of friends

It is guaranteed that only **one person** has the highest number of friends.

---

## 💡 Approach

Since friendship is **bidirectional**, every row contributes to **both users**.

### Steps

1. Select all `requester_id`.
2. Select all `accepter_id`.
3. Combine them using `UNION ALL`.
4. Count occurrences of each user using `GROUP BY`.
5. Sort by count in descending order.
6. Return the first record.

---

## ✅ MySQL Solution

```sql
SELECT id, COUNT(*) AS num
FROM (
    SELECT requester_id AS id
    FROM RequestAccepted

    UNION ALL

    SELECT accepter_id AS id
    FROM RequestAccepted
) AS friend_count
GROUP BY id
ORDER BY num DESC
LIMIT 1;
```

---

## 📖 Explanation

### Step 1

Collect every requester.

```sql
SELECT requester_id AS id
FROM RequestAccepted
```

Example:

| id |
|----|
|1|
|1|
|2|
|3|

---

### Step 2

Collect every accepter.

```sql
SELECT accepter_id AS id
FROM RequestAccepted
```

Example:

| id |
|----|
|2|
|3|
|3|
|4|

---

### Step 3

Merge both lists.

```sql
UNION ALL
```

Result:

| id |
|----|
|1|
|1|
|2|
|3|
|2|
|3|
|3|
|4|

Each appearance represents one friendship.

---

### Step 4

Count friends for each user.

```sql
GROUP BY id
```

Result:

| id | num |
|----|-----|
|1|2|
|2|2|
|3|3|
|4|1|

---

### Step 5

Return the user with the highest count.

```sql
ORDER BY num DESC
LIMIT 1;
```

Output:

| id | num |
|----|-----|
|3|3|
