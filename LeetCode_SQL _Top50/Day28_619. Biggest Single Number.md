## Problem Link

🔗 **LeetCode:** https://leetcode.com/problems/biggest-single-number/

## Approach

1. Group all numbers by `num`.
2. Keep only numbers that appear exactly once using `HAVING COUNT(*) = 1`.
3. Find the largest among those single-occurrence numbers using `MAX()`.

## MySQL Solution

```sql
WITH UniqueNums AS (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(num) = 1
)
SELECT MAX(num) AS num
FROM UniqueNums;
```

## Example

### Input

| num |
| --- |
| 8   |
| 8   |
| 3   |
| 3   |
| 1   |
| 4   |
| 5   |
| 6   |

### Output

| num |
| --- |
| 6   |

### Explanation

The numbers that appear only once are:

`1, 4, 5, 6`

The largest single number is:

`6`

## Complexity Analysis

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)` (for the CTE result)
