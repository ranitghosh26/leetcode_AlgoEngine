## 📌 Problem

**LeetCode 626 - Exchange Seats**

Swap the seat ID of every two consecutive students.

- If the number of students is **even**, every adjacent pair is swapped.
- If the number of students is **odd**, the last student remains unchanged.

🔗 **Problem Link:**  
https://leetcode.com/problems/exchange-seats/

---

## 💡 MySQL Solution

```sql
SELECT
    CASE
        WHEN id % 2 = 0 THEN id - 1
        WHEN id % 2 = 1
             AND (id + 1) <= (SELECT MAX(id) FROM Seat)
        THEN id + 1
        ELSE id
    END AS id,
    student
FROM Seat
ORDER BY id;
```

---

## 🧠 Explanation

The query uses a **CASE** statement to determine the new seat ID.

- If the current `id` is **even**, swap it with the previous seat (`id - 1`).
- If the current `id` is **odd** and another seat exists, swap it with the next seat (`id + 1`).
- If it is the **last student** in an odd-sized table, keep the same ID.

Finally, the result is sorted by the new `id` in ascending order.
