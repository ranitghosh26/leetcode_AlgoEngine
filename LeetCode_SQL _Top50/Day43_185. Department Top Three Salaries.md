## Problem Statement

Table: **Employee**

| Column Name | Type |
|-------------|------|
| id | int |
| name | varchar |
| salary | int |
| departmentId | int |

- `id` is the primary key.
- `departmentId` is a foreign key referencing `Department.id`.

Table: **Department**

| Column Name | Type |
|-------------|------|
| id | int |
| name | varchar |

- `id` is the primary key.

Find all employees whose salary belongs to the **top three unique salaries** within their department.

---

# MySQL Solution

```sql
SELECT d.name AS Department,
       e1.name AS Employee,
       e1.salary AS Salary
FROM Employee e1
INNER JOIN Department d
ON e1.departmentId = d.id
WHERE 3 > (
    SELECT COUNT(DISTINCT e2.salary)
    FROM Employee e2
    WHERE e2.salary > e1.salary
      AND e2.departmentId = e1.departmentId
);
```

---

## Explanation

- Join the **Employee** and **Department** tables.
- For each employee, count the number of **distinct salaries greater than their salary** within the same department.
- If there are fewer than **3 distinct higher salaries**, then that employee's salary is among the **top three unique salaries**.
- Return the department name, employee name, and salary.

---

## Complexity Analysis

- **Time Complexity:** **O(n²)**
- **Space Complexity:** **O(1)** (excluding query execution overhead)

---

## Key Takeaways

- Uses a **correlated subquery**.
- `COUNT(DISTINCT salary)` ensures duplicate salaries are counted only once.
- Employees with the **same salary** are all included.
- No window functions are required.
- Works in MySQL versions without `DENSE_RANK()` support.
