## 📝 Problem

Table: **Triangle**

| Column | Type |
|---------|------|
| x | int |
| y | int |
| z | int |

Each row contains the lengths of three line segments.

Determine whether the three line segments can form a triangle.

---

## ✅ MySQL Solution

```sql
SELECT
    x,
    y,
    z,
    CASE
        WHEN x + y > z
         AND x + z > y
         AND y + z > x
        THEN 'Yes'
        ELSE 'No'
    END AS triangle
FROM Triangle;
```

---

## 💡 Explanation

A triangle is valid only if the **sum of any two sides is greater than the third side**.

Conditions checked:

- `x + y > z`
- `x + z > y`
- `y + z > x`

If all conditions are true, return **'Yes'**; otherwise return **'No'**.
