## 📝 Problem Summary

Given two tables:

* **Prices**: Contains the price of each product during specific date ranges.
* **UnitsSold**: Contains sales transactions with units sold on specific dates.

Find the **average selling price** for each product:

[
\text{Average Selling Price} = \frac{\text{Total Revenue}}{\text{Total Units Sold}}
]

* Round the result to **2 decimal places**.
* If a product has no sales, return **0**.

---

## 💡 Approach

1. Join `Prices` and `UnitsSold` using:

   * `product_id`
   * `purchase_date` falling within the product's valid price period.
2. Calculate total revenue using:

   ```sql
   price * units
   ```
3. Divide total revenue by total units sold.
4. Use:

   * `ROUND(..., 2)` for 2 decimal places.
   * `IFNULL(..., 0)` for products without sales.

---

## ✅ MySQL Solution

```sql
SELECT 
    p.product_id, 
    IFNULL(
        ROUND(SUM(p.price * u.units) / SUM(u.units), 2),
        0
    ) AS average_price
FROM Prices p
LEFT JOIN UnitsSold u
    ON p.product_id = u.product_id
   AND u.purchase_date BETWEEN p.start_date AND p.end_date
GROUP BY p.product_id;
```

---

## ⏱ Complexity Analysis

| Operation   | Complexity |
| ----------- | ---------- |
| Join        | O(N + M)   |
| Aggregation | O(N)       |
| Total       | O(N + M)   |

Where:

* `N` = rows in `Prices`
* `M` = rows in `UnitsSold`
