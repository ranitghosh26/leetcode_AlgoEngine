# 2356. Number of Unique Subjects Taught by Each Teacher

[![LeetCode](https://img.shields.io/badge/LeetCode-2356-orange?style=for-the-badge\&logo=leetcode)](https://leetcode.com/problems/number-of-unique-subjects-taught-by-each-teacher/)

## Problem Link

🔗 https://leetcode.com/problems/number-of-unique-subjects-taught-by-each-teacher/

## SQL Solution (MySQL)

```sql
SELECT
    teacher_id,
    COUNT(DISTINCT subject_id) AS cnt
FROM
    Teacher
GROUP BY
    teacher_id;
```

## Explanation

* `COUNT(DISTINCT subject_id)` counts each subject only once for a teacher.
* The same subject taught in multiple departments is counted as a single unique subject.
* `GROUP BY teacher_id` calculates the result for each teacher separately.

## Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)

## Example

### Input

| teacher_id | subject_id | dept_id |
| ---------- | ---------- | ------- |
| 1          | 2          | 3       |
| 1          | 2          | 4       |
| 1          | 3          | 3       |
| 2          | 1          | 1       |
| 2          | 2          | 1       |
| 2          | 3          | 1       |
| 2          | 4          | 1       |

### Output

| teacher_id | cnt |
| ---------- | --- |
| 1          | 2   |
| 2          | 4   |
