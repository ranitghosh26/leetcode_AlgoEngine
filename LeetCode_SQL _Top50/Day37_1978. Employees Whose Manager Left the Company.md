## 📝 Problem

**1978. Employees Whose Manager Left the Company**

Given the `Employees` table, find the IDs of employees:

- 💰 Salary is **strictly less than 30000**
- 👨‍💼 Their **manager no longer exists** in the `Employees` table
- Return the result ordered by `employee_id`

🔗 **Problem Link:**  
https://leetcode.com/problems/employees-whose-manager-left-the-company/

---

## 💻 MySQL Solution

```sql
SELECT employee_id
FROM Employees
WHERE salary < 30000
  AND manager_id IS NOT NULL
  AND manager_id NOT IN (
      SELECT employee_id
      FROM Employees
  )
ORDER BY employee_id;
```

---

## ✅ Explanation

- Select employees whose **salary is less than 30000**.
- Ignore employees with **NULL manager_id**.
- Check whether the **manager_id does not exist** in the Employees table.
- Sort the result by **employee_id**.
