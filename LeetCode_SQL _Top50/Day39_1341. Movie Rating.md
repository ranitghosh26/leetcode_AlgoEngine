## 📌 Problem

**1341. Movie Rating**

Find:

1. The **user** who has rated the greatest number of movies.
   - If multiple users have the same count, return the **lexicographically smaller** name.

2. The **movie** with the highest average rating in **February 2020**.
   - If multiple movies have the same average rating, return the **lexicographically smaller** title.

---

## 💻 MySQL Solution

```sql
(SELECT name AS results
FROM MovieRating
JOIN Users USING(user_id)
GROUP BY name
ORDER BY COUNT(*) DESC, name
LIMIT 1)

UNION ALL

(SELECT title AS results
FROM MovieRating
JOIN Movies USING(movie_id)
WHERE EXTRACT(YEAR_MONTH FROM created_at) = 202002
GROUP BY title
ORDER BY AVG(rating) DESC, title
LIMIT 1);
```

---

## 🧠 Explanation

### ✅ Part 1: Find the Most Active User

- Join `MovieRating` with `Users`.
- Group by user name.
- Count the number of ratings for each user.
- Sort by:
  1. Rating count (Descending)
  2. User name (Ascending)
- Return the first row.

---

### ✅ Part 2: Find the Highest Rated Movie (February 2020)

- Join `MovieRating` with `Movies`.
- Filter ratings from **February 2020**.
- Group by movie title.
- Calculate `AVG(rating)`.
- Sort by:
  1. Average rating (Descending)
  2. Movie title (Ascending)
- Return the first row.

---

### ✅ UNION ALL

`UNION ALL` combines:

1. Top User
2. Top Movie

into a single result set.
