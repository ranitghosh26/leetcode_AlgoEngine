## 📌 Problem Statement

Given a `Logs` table:

| Column Name | Type |
|-------------|------|
| id | int |
| num | varchar |

- `id` is the primary key.
- `id` is an auto-increment column starting from `1`.

Find all numbers that appear **at least three times consecutively**.

---

## 💡 Approach

- Use the `LEAD()` window function to compare the current row with the next two rows.
- If all three values are equal, then the number appears at least three consecutive times.
- Use `DISTINCT` to avoid duplicate results.

---

## ✅ MySQL Solution

```sql
SELECT DISTINCT num AS ConsecutiveNums
FROM (
    SELECT num,
           LEAD(num, 1) OVER (ORDER BY id) AS next_1,
           LEAD(num, 2) OVER (ORDER BY id) AS next_2
    FROM Logs
) AS temp
WHERE num = next_1
  AND num = next_2;
```

## ⏱️ Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`
