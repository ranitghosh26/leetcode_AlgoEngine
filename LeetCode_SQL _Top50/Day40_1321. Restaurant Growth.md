## 📌 Problem

Given a **Customer** table containing customer transactions, calculate the **7-day moving total** and **7-day moving average** of the restaurant's revenue.

- Window = Current day + Previous 6 days
- Return:
  - `visited_on`
  - `amount` (7-day total revenue)
  - `average_amount` (rounded to 2 decimal places)
- Sort by `visited_on` in ascending order.

---

## 💻 MySQL Solution

```sql
SELECT visited_on,
(
    SELECT SUM(amount)
    FROM Customer
    WHERE visited_on BETWEEN DATE_SUB(c.visited_on, INTERVAL 6 DAY)
          AND c.visited_on
) AS amount,

ROUND((
    SELECT SUM(amount) / 7
    FROM Customer
    WHERE visited_on BETWEEN DATE_SUB(c.visited_on, INTERVAL 6 DAY)
          AND c.visited_on
), 2) AS average_amount

FROM Customer c

WHERE visited_on >= (
    SELECT DATE_ADD(MIN(visited_on), INTERVAL 6 DAY)
    FROM Customer
)

GROUP BY visited_on;
```

---

## 🧠 Explanation

- `DATE_SUB()` finds the previous **6 days**.
- `BETWEEN ... AND ...` selects the **7-day window**.
- `SUM(amount)` calculates the total revenue.
- `SUM(amount) / 7` calculates the moving average.
- `ROUND(..., 2)` formats the average to **2 decimal places**.
- `GROUP BY visited_on` ensures one result per day.
- The `WHERE` clause skips the first six days because a complete 7-day window is required.
