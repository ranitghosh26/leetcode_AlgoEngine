## 📝 Problem Statement

Write a query to find managers who have **at least five direct reports**.

The result should return the manager's name.

---

## 💡 Approach

1. Group employees by `managerId`.
2. Count the number of employees reporting to each manager.
3. Filter managers having `COUNT(id) >= 5`.
4. Retrieve the corresponding manager names using their `id`.

**Time Complexity:** `O(n)`
**Space Complexity:** `O(n)`

---

## ✅ MySQL Solution

```sql
SELECT name
FROM Employee
WHERE id IN (
    SELECT managerId
    FROM Employee
    GROUP BY managerId
    HAVING COUNT(id) >= 5
);
```

## 📊 Example

| 104 | Amy   | A          | 101       |
