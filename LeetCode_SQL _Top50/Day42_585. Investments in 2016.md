## 📌 Problem

Table: **Insurance**

| Column Name | Type |
|-------------|------|
| pid | int |
| tiv_2015 | float |
| tiv_2016 | float |
| lat | float |
| lon | float |

Each row contains insurance policy information.

Find the **sum of all `tiv_2016` values** for policyholders who satisfy both conditions:

1. Their **`tiv_2015` value appears more than once**.
2. Their **location (`lat`, `lon`) is unique** (no other policyholder has the same coordinates).

Return the answer rounded to **2 decimal places**.

---

# 💡 Approach

We need to satisfy **two conditions**.

### Step 1: Find duplicate `tiv_2015`

Use `GROUP BY` and `HAVING COUNT(*) > 1`.

```sql
SELECT tiv_2015
FROM Insurance
GROUP BY tiv_2015
HAVING COUNT(*) > 1;
```

---

### Step 2: Find unique locations

Group by `(lat, lon)`.

```sql
SELECT lat, lon
FROM Insurance
GROUP BY lat, lon
HAVING COUNT(*) = 1;
```

---

### Step 3: Filter records satisfying both conditions

- `tiv_2015` must be duplicated.
- `(lat, lon)` must be unique.
- Sum all matching `tiv_2016`.
- Round to 2 decimal places.

---

# ✅ MySQL Solution

```sql
SELECT ROUND(SUM(tiv_2016), 2) AS tiv_2016
FROM Insurance
WHERE tiv_2015 IN (
    SELECT tiv_2015
    FROM Insurance
    GROUP BY tiv_2015
    HAVING COUNT(*) > 1
)
AND (lat, lon) IN (
    SELECT lat, lon
    FROM Insurance
    GROUP BY lat, lon
    HAVING COUNT(*) = 1
);
```
