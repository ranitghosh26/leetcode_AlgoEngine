## Approach

For each **month** and **country**:

* Count total transactions.
* Count approved transactions.
* Sum total transaction amounts.
* Sum amounts of approved transactions.

### Key SQL Concepts Used

* `DATE_FORMAT()` to extract `YYYY-MM`.
* `GROUP BY` month and country.
* Conditional aggregation using:

  * `SUM(state = 'approved')`
  * `CASE WHEN ... THEN ... END`

---

## MySQL Solution

```sql
SELECT 
    DATE_FORMAT(trans_date, '%Y-%m') AS month,
    country,
    COUNT(*) AS trans_count,
    SUM(state = 'approved') AS approved_count,
    SUM(amount) AS trans_total_amount,
    SUM(CASE WHEN state = 'approved' THEN amount ELSE 0 END) AS approved_total_amount
FROM 
    Transactions
GROUP BY 
    DATE_FORMAT(trans_date, '%Y-%m'),
    country;
```

## Example

### Input

| id  | country | state    | amount | trans_date |
| --- | ------- | -------- | ------ | ---------- |
| 121 | US      | approved | 1000   | 2018-12-18 |
| 122 | US      | declined | 2000   | 2018-12-19 |
| 123 | US      | approved | 2000   | 2019-01-01 |
| 124 | DE      | approved | 2000   | 2019-01-07 |

### Output

| month   | country | trans_count | approved_count | trans_total_amount | approved_total_amount |
| ------- | ------- | ----------- | -------------- | ------------------ | --------------------- |
| 2018-12 | US      | 2           | 1              | 3000               | 1000                  |
| 2019-01 | US      | 1           | 1              | 2000               | 2000                  |
| 2019-01 | DE      | 1           | 1              | 2000               | 2000                  |

## Complexity Analysis

* **Time Complexity:** `O(N)`
* **Space Complexity:** `O(G)`

Where:

* `N` = number of rows in `Transactions`
* `G` = number of `(month, country)` groups
