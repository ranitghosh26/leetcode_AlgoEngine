## SQL Solution (MySQL)

```sql
SELECT 
    mgr.employee_id,
    mgr.name,
    COUNT(emp.employee_id) AS reports_count,
    ROUND(AVG(emp.age)) AS average_age
FROM Employees mgr
INNER JOIN Employees emp
    ON mgr.employee_id = emp.reports_to
GROUP BY
    mgr.employee_id,
    mgr.name
ORDER BY
    mgr.employee_id;
```

---

## Explanation

### Approach

* Perform a self-join on the `Employees` table.
* Treat `mgr` as the manager table and `emp` as the employee table.
* Match employees with their managers using:

```sql
mgr.employee_id = emp.reports_to
```

* Count direct reports using:

```sql
COUNT(emp.employee_id)
```

* Calculate the average age of reporting employees:

```sql
AVG(emp.age)
```

* Round the average age to the nearest integer:

```sql
ROUND(AVG(emp.age))
```

* Group results by manager ID and name.
* Sort the output by `employee_id`.
