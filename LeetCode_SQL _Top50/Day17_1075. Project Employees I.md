# 1075. Project Employees I

## SQL Solution (MySQL)

```sql
SELECT 
    p.project_id, 
    ROUND(AVG(e.experience_years), 2) AS average_years
FROM 
    Project p
INNER JOIN 
    Employee e
ON 
    p.employee_id = e.employee_id
GROUP BY 
    p.project_id;
```

---

## Explanation

1. Join the `Project` and `Employee` tables using `employee_id`.
2. Group records by `project_id`.
3. Calculate the average experience of employees assigned to each project using `AVG()`.
4. Use `ROUND(..., 2)` to round the result to 2 decimal places.
