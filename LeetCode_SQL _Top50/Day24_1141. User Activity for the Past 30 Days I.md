## SQL Solution

```sql
SELECT 
    activity_date AS day, 
    COUNT(DISTINCT user_id) AS active_users
FROM Activity
WHERE activity_date BETWEEN '2019-06-28' AND '2019-07-27'
GROUP BY activity_date;
```

## Explanation

- The problem asks for the number of **active users per day** within the 30-day period ending on **2019-07-27**.
- A user is considered active if they perform **at least one activity** on a given day.
- `COUNT(DISTINCT user_id)` ensures each user is counted only once per day.
- The `WHERE` clause filters records between **2019-06-28** and **2019-07-27** (inclusive).
- Results are grouped by `activity_date`.
