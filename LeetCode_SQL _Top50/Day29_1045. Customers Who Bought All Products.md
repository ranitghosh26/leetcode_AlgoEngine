## Solution

To find customers who bought **all products**, we:

1. Count the number of **distinct products** purchased by each customer.
2. Compare it with the **total number of products** available in the `Product` table.
3. Return customers where both counts are equal.

### MySQL Query

```sql
SELECT customer_id
FROM Customer
GROUP BY customer_id
HAVING COUNT(DISTINCT product_key) = (
    SELECT COUNT(*)
    FROM Product
);
```

---

## Example

### Input

**Customer**

| customer_id | product_key |
| ----------- | ----------- |
| 1           | 5           |
| 2           | 6           |
| 3           | 5           |
| 3           | 6           |
| 1           | 6           |

**Product**

| product_key |
| ----------- |
| 5           |
| 6           |

### Output

| customer_id |
| ----------- |
| 1           |
| 3           |

### Explanation

* Customer **1** purchased products **5** and **6**.
* Customer **3** purchased products **5** and **6**.
* Customer **2** purchased only product **6**.

Therefore, customers **1** and **3** bought all available products.
