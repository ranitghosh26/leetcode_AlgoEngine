# 1729. Find Followers Count

[![LeetCode](https://img.shields.io/badge/LeetCode-1729%20Find%20Followers%20Count-orange?logo=leetcode\&logoColor=white)](https://leetcode.com/problems/find-followers-count/)

## Problem Link

🔗 https://leetcode.com/problems/find-followers-count/

## SQL Solution (MySQL)

```sql
SELECT 
    user_id, 
    COUNT(follower_id) AS followers_count
FROM 
    Followers
GROUP BY 
    user_id
ORDER BY 
    user_id ASC;
```

## Explanation

* `COUNT(follower_id)` counts the number of followers for each user.
* `GROUP BY user_id` groups all follower records belonging to the same user.
* `ORDER BY user_id ASC` sorts the result by `user_id` in ascending order.

### Example

**Input**

| user_id | follower_id |
| ------- | ----------- |
| 0       | 1           |
| 1       | 0           |
| 2       | 0           |
| 2       | 1           |

**Output**

| user_id | followers_count |
| ------- | --------------- |
| 0       | 1               |
| 1       | 1               |
| 2       | 2               |

## Complexity Analysis

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(1)` (excluding output storage)
