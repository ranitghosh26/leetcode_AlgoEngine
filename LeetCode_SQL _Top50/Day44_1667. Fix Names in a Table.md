# LeetCode 1667 — Fix Names in a Table

[![LeetCode](https://img.shields.io/badge/LeetCode-1667-orange?logo=leetcode)](https://leetcode.com/problems/fix-names-in-a-table/)
[![MySQL](https://img.shields.io/badge/MySQL-SQL-blue?logo=mysql)](https://www.mysql.com/)

## 📌 Problem

Given a `Users` table containing `user_id` and `name`, fix each user's name so that:

* The **first character is uppercase**
* All remaining characters are **lowercase**
* Return the result ordered by `user_id`

### Example

**Input:**

| user_id | name  |
| ------: | ----- |
|       1 | aLice |
|       2 | bOB   |

**Output:**

| user_id | name  |
| ------: | ----- |
|       1 | Alice |
|       2 | Bob   |

---

## 💡 Approach

We can use three MySQL string functions:

* `LEFT(name, 1)` → gets the first character
* `UPPER(...)` → converts it to uppercase
* `RIGHT(name, LENGTH(name) - 1)` → gets all characters except the first
* `LOWER(...)` → converts the remaining characters to lowercase
* `CONCAT(...)` → combines the two parts

### Formula

```text
UPPER(first character) + LOWER(remaining characters)
```

For example:

```text
aLice
 ↓
A + lice
 ↓
Alice
```

---

## 💻 MySQL Solution

```sql
SELECT user_id,
       CONCAT(
           UPPER(LEFT(name, 1)),
           LOWER(RIGHT(name, LENGTH(name) - 1))
       ) AS name
FROM Users
ORDER BY user_id;
```

---

## 🔍 Explanation of the Query

```sql
LEFT(name, 1)
```

Gets the first character.

Example:

```text
aLice → a
```

Then:

```sql
UPPER(LEFT(name, 1))
```

Converts it to uppercase:

```text
a → A
```

Next:

```sql
RIGHT(name, LENGTH(name) - 1)
```

Gets everything except the first character:

```text
aLice → Lice
```

Then:

```sql
LOWER(RIGHT(name, LENGTH(name) - 1))
```

Converts the remaining characters to lowercase:

```text
Lice → lice
```

Finally:

```sql
CONCAT(...)
```

Combines them:

```text
A + lice = Alice
```

And:

```sql
ORDER BY user_id;
```

ensures the result is sorted by `user_id`.

---

## ⏱️ Complexity

* **Time:** `O(n × L)` where `n` is the number of users and `L` is the average name length.
* **Space:** `O(n)` for the returned result.
