# 596. Classes With at Least 5 Students

[![LeetCode](https://img.shields.io/badge/LeetCode-Problem_596-orange?logo=leetcode&logoColor=white)](https://leetcode.com/problems/classes-with-at-least-5-students/)

## Problem Link

🔗 https://leetcode.com/problems/classes-with-at-least-5-students/

## SQL Solution (MySQL)

```sql
SELECT 
    class
FROM 
    Courses
GROUP BY 
    class
HAVING 
    COUNT(student) >= 5;
```

## Explanation

- Group records by `class`.
- Count the number of students in each class using `COUNT(student)`.
- Filter classes having at least **5 students** using the `HAVING` clause.

## Complexity Analysis

- **Time Complexity:** O(n)
- **Space Complexity:** O(k)

Where:
- `n` = total number of rows in the `Courses` table.
- `k` = number of distinct classes.
