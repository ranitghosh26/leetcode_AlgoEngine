## 📝 MySQL Solution

```sql
SELECT
    'Low Salary' AS category,
    COUNT(*) AS accounts_count
FROM Accounts
WHERE income < 20000

UNION

SELECT
    'Average Salary' AS category,
    COUNT(*) AS accounts_count
FROM Accounts
WHERE income BETWEEN 20000 AND 50000

UNION

SELECT
    'High Salary' AS category,
    COUNT(*) AS accounts_count
FROM Accounts
WHERE income > 50000;
```

---

## 💡 Explanation

The solution uses **three separate SELECT statements**, each representing one salary category:

- **Low Salary** → `income < 20000`
- **Average Salary** → `income BETWEEN 20000 AND 50000`
- **High Salary** → `income > 50000`

Each query counts the number of accounts in its category using `COUNT(*)`. The results are combined using `UNION`, ensuring all three categories are always returned, even when a category has zero matching accounts.
