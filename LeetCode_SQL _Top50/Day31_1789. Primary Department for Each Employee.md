## Solution (MySQL)

```sql
SELECT employee_id, department_id
FROM Employee
WHERE primary_flag = 'Y'

UNION

SELECT employee_id, department_id
FROM Employee
GROUP BY employee_id
HAVING COUNT(employee_id) = 1;
```

## Explanation

* Employees with `primary_flag = 'Y'` already have a designated primary department.
* If an employee belongs to only one department, there will be no `'Y'` flag, so we return their only department using:

  ```sql
  GROUP BY employee_id
  HAVING COUNT(employee_id) = 1
  ```
* `UNION` combines both result sets and removes duplicates.

## Complexity Analysis

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)` (for the UNION operation)
