## Problem Link

🔗 **LeetCode:** https://leetcode.com/problems/confirmation-rate/

## Approach

* Use a `LEFT JOIN` to include all users from the `Signups` table.

* Convert `'confirmed'` actions to `1` and all others (`'timeout'` or `NULL`) to `0`.

* Compute the average per user:

  `confirmation rate = confirmed messages / total messages`

* `AVG()` automatically calculates the ratio.

* `ROUND(..., 2)` formats the result to two decimal places.

* Users with no confirmation requests will have a rate of `0.00`.

## MySQL Solution

```sql
SELECT 
    s.user_id,
    ROUND(AVG(IF(c.action = 'confirmed', 1, 0)), 2) AS confirmation_rate
FROM Signups s
LEFT JOIN Confirmations c
    ON s.user_id = c.user_id
GROUP BY s.user_id;
```

## Complexity Analysis

* **Time Complexity:** O(N + M)
* **Space Complexity:** O(1)

Where:

* `N` = number of rows in `Signups`
* `M` = number of rows in `Confirmations`
