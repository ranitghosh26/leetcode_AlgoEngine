## 📌 Problem Summary

Given three tables:

* **Students** → Student ID and Name
* **Subjects** → List of subjects
* **Examinations** → Records of exams attended by students

Find the number of times each student attended each subject exam.

The output should contain **all possible student-subject combinations**, including those with **0 attended exams**, ordered by:

1. `student_id`
2. `subject_name`

---

## 💡 Approach

1. Use **CROSS JOIN** to generate every possible combination of students and subjects.
2. Use **LEFT JOIN** with the `Examinations` table to keep combinations even when no exam was attended.
3. Use **COUNT()** to count the number of attended exams.
4. Group by student and subject.
5. Sort the result by `student_id` and `subject_name`.

---

## ✅ MySQL Solution

```sql
SELECT 
    s.student_id,
    s.student_name,
    sub.subject_name,
    COUNT(e.subject_name) AS attended_exams
FROM Students s
CROSS JOIN Subjects sub
LEFT JOIN Examinations e
    ON s.student_id = e.student_id
    AND sub.subject_name = e.subject_name
GROUP BY
    s.student_id,
    s.student_name,
    sub.subject_name
ORDER BY
    s.student_id,
    sub.subject_name;
```

---

## ⏱ Complexity Analysis

| Operation         | Complexity     |
| ----------------- | -------------- |
| CROSS JOIN        | O(S × Sub)     |
| LEFT JOIN + COUNT | O(E)           |
| Overall           | O(S × Sub + E) |

Where:

* `S` = Number of students
* `Sub` = Number of subjects
* `E` = Number of examination records
