## 📝 Problem Summary

Find the fraction of players who logged in again on the day immediately after their first login date.

The result should be rounded to **2 decimal places**.

---

## 💡 MySQL Solution

```sql
SELECT 
    ROUND(
        COUNT(DISTINCT player_id) / 
        (SELECT COUNT(DISTINCT player_id) FROM Activity),
        2
    ) AS fraction
FROM Activity
WHERE (player_id, DATE_SUB(event_date, INTERVAL 1 DAY)) IN (
    SELECT player_id, MIN(event_date)
    FROM Activity
    GROUP BY player_id
);
```

---

## 🔍 Explanation

1. Find each player's first login date using:

```sql
SELECT player_id, MIN(event_date)
FROM Activity
GROUP BY player_id;
```

2. Check whether the player logged in on the very next day:

```sql
DATE_SUB(event_date, INTERVAL 1 DAY)
```

3. Count all such players and divide by the total number of distinct players.

4. Round the result to **2 decimal places** using:

```sql
ROUND(..., 2)
```

---

## 📊 Example

Input:

| player_id | event_date |
| --------- | ---------- |
| 1         | 2016-03-01 |
| 1         | 2016-03-02 |
| 2         | 2017-06-25 |
| 3         | 2016-03-02 |
| 3         | 2018-07-03 |

Output:

```text
0.33
```

Explanation:

* Player 1 logged in again the day after the first login.
* Players 2 and 3 did not.

Fraction = 1 / 3 = **0.33**
