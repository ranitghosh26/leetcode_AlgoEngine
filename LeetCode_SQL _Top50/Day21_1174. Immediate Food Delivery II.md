## 📝 Problem Summary

A customer's order is considered:

* **Immediate** if `order_date = customer_pref_delivery_date`
* **Scheduled** otherwise

The task is to find the **percentage of immediate orders among the first orders of all customers**, rounded to **2 decimal places**.

---

## 💡 Approach

1. Find the **first order** for each customer using `MIN(order_date)`.
2. Filter only those first orders.
3. Count how many are **immediate**.
4. Calculate the percentage:

   `immediate_orders / total_first_orders × 100`

---

## ✅ MySQL Solution

```sql
SELECT 
    ROUND(
        SUM(
            CASE 
                WHEN order_date = customer_pref_delivery_date 
                THEN 1 
                ELSE 0 
            END
        ) * 100.0 / COUNT(*),
        2
    ) AS immediate_percentage
FROM Delivery
WHERE (customer_id, order_date) IN (
    SELECT customer_id, MIN(order_date)
    FROM Delivery
    GROUP BY customer_id
);
```
