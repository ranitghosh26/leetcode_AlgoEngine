## 📝 Problem Statement

Write a solution to find the average time each machine takes to complete a process.

The completion time of a process is:

end timestamp - start timestamp

The average processing time should be rounded to **3 decimal places**.

---

## 💡 MySQL Solution

```sql
SELECT 
    machine_id,
    ROUND(
        SUM(
            CASE 
                WHEN activity_type = 'end' 
                THEN timestamp 
                ELSE -timestamp 
            END
        ) 
        / COUNT(DISTINCT process_id), 
        3
    ) AS processing_time
FROM Activity
GROUP BY machine_id;
```

---

## ⚡ Explanation

### ✔️ Logic Used

* `start` timestamps are subtracted
* `end` timestamps are added
* This gives total processing time for each machine
* Divide by number of distinct processes
* `ROUND(..., 3)` formats the answer to 3 decimal places

---

## ✅ Example

### Input

| machine_id | process_id | activity_type | timestamp |
| ---------- | ---------- | ------------- | --------- |
| 0          | 0          | start         | 0.712     |
| 0          | 0          | end           | 1.520     |

### Processing Time

```text
1.520 - 0.712 = 0.808
```
