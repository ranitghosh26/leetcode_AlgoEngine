## 📖 Problem Summary

Given the `Sales` table, find all sales records that occurred in the **first year** each product was sold.

For every `product_id`:

* Determine the earliest year it appears in the table.
* Return all sales entries from that first year.

### Required Output

| Column     | Description                     |
| ---------- | ------------------------------- |
| product_id | Product identifier              |
| first_year | First year the product was sold |
| quantity   | Quantity sold in the first year |
| price      | Product price in the first year |

---

## 💡 Approach

1. Find the minimum (`MIN(year)`) for each `product_id`.
2. Match the `(product_id, year)` pair with the original table.
3. Return the corresponding `quantity` and `price`.

---

## ✅ MySQL Solution

```sql
SELECT 
    product_id, 
    year AS first_year, 
    quantity, 
    price
FROM 
    Sales
WHERE 
    (product_id, year) IN (
        SELECT 
            product_id, 
            MIN(year)
        FROM 
            Sales
        GROUP BY 
            product_id
    );
```
