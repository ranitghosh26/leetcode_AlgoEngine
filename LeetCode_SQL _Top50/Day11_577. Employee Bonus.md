# 577. Employee Bonus (LeetCode)

[![LeetCode](https://img.shields.io/badge/LeetCode-577.%20Employee%20Bonus-orange?logo=leetcode)](https://leetcode.com/problems/employee-bonus/)

## Problem Link

🔗 https://leetcode.com/problems/employee-bonus/

## SQL Solution (MySQL)

```sql
SELECT 
    e.name, 
    b.bonus
FROM Employee e
LEFT JOIN Bonus b
    ON e.empId = b.empId
WHERE b.bonus < 1000
   OR b.bonus IS NULL;
```

## Explanation

* Use a **LEFT JOIN** to include all employees, even those who do not have a bonus record.
* Employees with:

  * `bonus < 1000`, or
  * `NULL` bonus (no bonus received)

  are selected using the `WHERE` clause.

## Example

### Input

**Employee**

| empId | name   | supervisor | salary |
| ----- | ------ | ---------- | ------ |
| 3     | Brad   | NULL       | 4000   |
| 1     | John   | 3          | 1000   |
| 2     | Dan    | 3          | 2000   |
| 4     | Thomas | 3          | 4000   |

**Bonus**

| empId | bonus |
| ----- | ----- |
| 2     | 500   |
| 4     | 2000  |

### Output

| name | bonus |
| ---- | ----- |
| Brad | NULL  |
| John | NULL  |
| Dan  | 500   |

## Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1) (excluding output)
