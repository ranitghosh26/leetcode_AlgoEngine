# 1581. Customer Who Visited but Did Not Make Any Transactions

## Problem Statement

Given two tables:

### Visits

| Column Name | Type |
| ----------- | ---- |
| visit_id    | int  |
| customer_id | int  |

* `visit_id` is unique.
* Contains information about customers who visited the mall.

### Transactions

| Column Name    | Type |
| -------------- | ---- |
| transaction_id | int  |
| visit_id       | int  |
| amount         | int  |

* `transaction_id` is unique.
* Contains information about transactions made during visits.

---

## Task

Find the IDs of customers who visited the mall **without making any transactions**, along with the number of such visits.

Return the result table in any order.

---

## Example

### Input

### Visits

| visit_id | customer_id |
| -------- | ----------- |
| 1        | 23          |
| 2        | 9           |
| 4        | 30          |
| 5        | 54          |
| 6        | 96          |
| 7        | 54          |
| 8        | 54          |

### Transactions

| transaction_id | visit_id | amount |
| -------------- | -------- | ------ |
| 2              | 5        | 310    |
| 3              | 5        | 300    |
| 9              | 5        | 200    |
| 12             | 1        | 910    |
| 13             | 2        | 970    |

---

### Output

| customer_id | count_no_trans |
| ----------- | -------------- |
| 54          | 2              |
| 30          | 1              |
| 96          | 1              |

---

## Explanation

* Customer `23` made a transaction during the visit.
* Customer `9` made a transaction during the visit.
* Customer `30` visited once without any transaction.
* Customer `54` visited three times:

  * One visit had transactions.
  * Two visits had no transactions.
* Customer `96` visited once without any transaction.

---

# MySQL Solution

```sql
SELECT 
    v.customer_id, 
    COUNT(v.visit_id) AS count_no_trans
FROM 
    Visits v
LEFT JOIN 
    Transactions t 
ON 
    v.visit_id = t.visit_id
WHERE 
    t.transaction_id IS NULL
GROUP BY 
    v.customer_id;
```

---

# Approach

1. Use a `LEFT JOIN` to combine `Visits` and `Transactions`.
2. Visits without transactions will have `NULL` values in the transaction columns.
3. Filter those records using:

```sql
WHERE t.transaction_id IS NULL
```

4. Group by `customer_id`.
5. Count the number of visits without transactions.

---

# Complexity Analysis

* **Time Complexity:** `O(N)`
* **Space Complexity:** `O(1)` (excluding output storage)
