## 📝 Problem Statement

Given a `Cinema` table:

| Column Name | Type |
|------------|------|
| id | int |
| movie | varchar |
| description | varchar |
| rating | float |

- `id` is the primary key.
- Each row contains information about a movie, its description, and rating.

### Task

Report all movies that:

- Have an **odd-numbered ID**
- Have a **description other than "boring"**

Return the result ordered by **rating in descending order**.

---

## 💡 Approach

1. Filter records where `id` is odd using `id % 2 != 0`.
2. Exclude movies with `description = 'boring'`.
3. Sort the remaining rows by `rating` in descending order.

---

## ✅ MySQL Solution

```sql
SELECT *
FROM Cinema
WHERE id % 2 != 0
  AND description != 'boring'
ORDER BY rating DESC;
```

---

## ⏱️ Complexity Analysis

- **Time Complexity:** O(n log n) (due to sorting)
- **Space Complexity:** O(1)

---

## 🎯 Example

### Input

| id | movie | description | rating |
|----|--------|------------|--------|
| 1 | War | great 3D | 8.9 |
| 2 | Science | fiction | 8.5 |
| 3 | irish | boring | 6.2 |
| 4 | Ice song | Fantacy | 8.6 |
| 5 | House card | Interesting | 9.1 |

### Output

| id | movie | description | rating |
|----|--------|------------|--------|
| 5 | House card | Interesting | 9.1 |
| 1 | War | great 3D | 8.9 |
