## 💡 MySQL Solution

```sql
SELECT q1.person_name
FROM Queue q1
INNER JOIN Queue q2
    ON q1.turn >= q2.turn
GROUP BY q1.turn
HAVING SUM(q2.weight) <= 1000
ORDER BY SUM(q2.weight) DESC
LIMIT 1;
```

---

## 🧠 Explanation

- Join the `Queue` table with itself.
- For each person (`q1`), include everyone whose `turn` is less than or equal to that person's turn.
- Calculate the cumulative weight using `SUM(q2.weight)`.
- Keep only those cumulative weights that do not exceed **1000 kg**.
- Sort by the highest valid cumulative weight.
- Return the corresponding `person_name`.

**Time Complexity:** `O(n²)`  
**Space Complexity:** `O(1)` (excluding query execution internals)
