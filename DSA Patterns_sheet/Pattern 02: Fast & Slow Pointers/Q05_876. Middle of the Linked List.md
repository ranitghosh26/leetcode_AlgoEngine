# 876. Middle of the Linked List

**LeetCode:** 876  
**Difficulty:** Easy

---

# Problem Statement

Given the `head` of a singly linked list, return the **middle node** of the linked list.

- If the list has **two middle nodes**, return the **second middle node**.

---

## Example 1

**Input**

```text
head = [1,2,3,4,5]
```

**Output**

```text
[3,4,5]
```

**Explanation**

```
1 → 2 → 3 → 4 → 5
          ↑
       Middle
```

---

## Example 2

**Input**

```text
head = [1,2,3,4,5,6]
```

**Output**

```text
[4,5,6]
```

**Explanation**

```
1 → 2 → 3 → 4 → 5 → 6
              ↑
      Second Middle
```

---

# Fast & Slow Pointer Approach

## Idea

Use two pointers:

- **Slow Pointer** → moves **1 step** at a time.
- **Fast Pointer** → moves **2 steps** at a time.

When the **fast pointer reaches the end**, the **slow pointer will be at the middle**.

---

## Dry Run

### Example

```
1 → 2 → 3 → 4 → 5
```

| Iteration | Slow | Fast |
|-----------|------|------|
| Start | 1 | 1 |
| 1 | 2 | 3 |
| 2 | 3 | 5 |
| Stop | 3 | End |

Answer = Node **3**

---

### Even Length Example

```
1 → 2 → 3 → 4 → 5 → 6
```

| Iteration | Slow | Fast |
|-----------|------|------|
| Start | 1 | 1 |
| 1 | 2 | 3 |
| 2 | 3 | 5 |
| 3 | 4 | End |

Answer = Node **4**

---

# Algorithm

1. Initialize:
   - `slow = head`
   - `fast = head`
2. While `fast != null` and `fast.next != null`
   - Move `slow` by one step.
   - Move `fast` by two steps.
3. Return `slow`.

---

# Java Solution

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *
 *     ListNode() {}
 *
 *     ListNode(int val) {
 *         this.val = val;
 *     }
 *
 *     ListNode(int val, ListNode next) {
 *         this.val = val;
 *         this.next = next;
 *     }
 * }
 */

class Solution {

    public ListNode middleNode(ListNode head) {

        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {

            slow = slow.next;
            fast = fast.next.next;

        }

        return slow;
    }
}
```

---

# Complexity Analysis

| Complexity | Value |
|------------|-------|
| Time | **O(n)** |
| Space | **O(1)** |

- Every node is visited at most once.
- No extra data structure is used.

---

# Why Does This Work?

- The **fast pointer** moves twice as fast as the **slow pointer**.
- When the fast pointer reaches the last node (or passes it), the slow pointer has covered only half the distance.
- Therefore, the slow pointer is exactly at the middle.

For an **even-length** list, the loop ends after the slow pointer moves to the **second middle node**, which matches the problem requirement.
