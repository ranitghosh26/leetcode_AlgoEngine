# 143. Reorder List

**Difficulty:** Medium

## 🔗 Problem Link

---

## 📝 Problem Statement

You are given the head of a singly linked list.

```
L0 → L1 → L2 → ... → Ln
```

Reorder it into:

```
L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → ...
```

You may **not modify the values** in the list's nodes. Only the node links may be changed.

### Example 1

Input

```
head = [1,2,3,4]
```

Output

```
[1,4,2,3]
```

### Example 2

Input

```
head = [1,2,3,4,5]
```

Output

```
[1,5,2,4,3]
```
