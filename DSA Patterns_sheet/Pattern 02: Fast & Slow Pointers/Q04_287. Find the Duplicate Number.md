# 287. Find the Duplicate Number

🔗 **LeetCode Problem:** https://leetcode.com/problems/find-the-duplicate-number/

**Difficulty:** Medium

---

## Problem Statement

Given an integer array `nums` containing `n + 1` integers where each integer is in the range `[1, n]` inclusive.

There is only **one repeated number** in `nums`. Return that repeated number.

### Constraints

- Do **not** modify the array.
- Use only **constant extra space**.
- Time complexity should be efficient.

---

## Approach: Floyd's Tortoise and Hare (Fast & Slow Pointer)

### Intuition

Treat the array like a **linked list**.

- Each index points to the next index using its value.
- Since one number is duplicated, two indices point to the same value.
- This creates a **cycle** in the linked list.

Floyd's Cycle Detection Algorithm helps us:

1. Detect the cycle.
2. Find the entrance of the cycle.
3. The entrance is the duplicate number.

---

## Algorithm

### Phase 1: Detect Cycle

- Initialize:
  - `slow = nums[0]`
  - `fast = nums[0]`
- Move:
  - `slow = nums[slow]`
  - `fast = nums[nums[fast]]`
- Continue until they meet.

### Phase 2: Find Cycle Entrance

- Reset:
  - `slow = nums[0]`
- Move both one step at a time:
  - `slow = nums[slow]`
  - `fast = nums[fast]`
- When they meet again, that value is the duplicate number.

---

## Java Solution (Using `do-while`)

```java
class Solution {
    public int findDuplicate(int[] nums) {

        int slow = nums[0];
        int fast = nums[0];

        // Phase 1: Detect the cycle
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);

        // Phase 2: Find the entrance of the cycle
        slow = nums[0];

        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }

        return slow;
    }
}
```

---

## Alternative Java Solution (Using `while(true)`)

This implementation follows the same Floyd's Cycle Detection Algorithm but starts both pointers from index `0` and uses an infinite loop until the cycle is detected.

```java
class Solution {
    public int findDuplicate(int[] nums) {
        int slow = 0;
        int fast = 0;

        while (true) {
            slow = nums[slow];
            fast = nums[fast];
            fast = nums[fast];

            // Meeting point (cycle detected)
            if (slow == fast) {

                slow = 0;

                // Find the starting point of the cycle
                while (slow != fast) {
                    slow = nums[slow];
                    fast = nums[fast];
                }

                return slow;
            }
        }
    }
}
```

### Difference Between the Two Implementations

| `do-while` Version | `while(true)` Version |
|--------------------|----------------------|
| Starts from `nums[0]` | Starts from index `0` |
| Uses `do-while` to ensure one iteration | Uses `while(true)` with a break condition (`return`) |
| Moves `fast` using `nums[nums[fast]]` | Moves `fast` in two separate steps |
| Slightly shorter | More explicit pointer movement |

Both implementations have the same:

- ✅ Time Complexity: **O(n)**
- ✅ Space Complexity: **O(1)**
- ✅ Floyd's Cycle Detection Algorithm
- ✅ Do not modify the array

Duplicate = **2**

### Phase 1

| Step | Slow | Fast |
|------|------|------|
| Start | 1 | 1 |
| 1 | 3 | 2 |
| 2 | 2 | 2 |

Cycle detected.

---

### Phase 2

Reset slow.

| Step | Slow | Fast |
|------|------|------|
| Start | 1 | 2 |
| 1 | 3 | 4 |
| 2 | 2 | 2 |

Answer = **2**

## Why This Works

Since every number lies in the range `[1, n]`, every value points to another valid index.

The duplicate number creates multiple incoming edges to the same node, producing a cycle.

Floyd's algorithm guarantees that the cycle entrance is the duplicate number.

## Key Takeaways

- Do **not** sort the array.
- Do **not** use a HashSet.
- Do **not** modify the array.
- Floyd's Cycle Detection satisfies all constraints:
  - ✅ O(n) Time
  - ✅ O(1) Extra Space
  - ✅ Original array remains unchanged
