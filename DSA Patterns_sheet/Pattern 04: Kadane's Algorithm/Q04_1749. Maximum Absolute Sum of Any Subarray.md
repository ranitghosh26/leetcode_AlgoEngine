# 1749. Maximum Absolute Sum of Any Subarray

**LeetCode Link:** https://leetcode.com/problems/maximum-absolute-sum-of-any-subarray/

**Difficulty:** Medium

---

## Problem

Given an integer array `nums`, the **absolute sum** of a subarray is

\[
|nums[l] + nums[l+1] + ... + nums[r]|
\]

Return the **maximum absolute sum** among all possible subarrays.

A subarray may also be empty, whose sum is `0`.

---

## Example 1

Input

```text
nums = [1,-3,2,3,-4]
```

Output

```text
5
```

Explanation

```
Subarray = [2,3]

Sum = 5

Absolute Sum = |5| = 5
```

---

## Example 2

Input

```text
nums = [2,-5,1,-4,3,-2]
```

Output

```text
8
```

Explanation

```
Subarray = [-5,1,-4]

Sum = -8

Absolute Sum = |-8| = 8
```

---

# Intuition

The absolute value becomes maximum in **two situations**:

1. The maximum positive subarray sum.
2. The minimum (most negative) subarray sum.

Example

```
Subarray Sum = 12

Absolute = 12
```

or

```
Subarray Sum = -15

Absolute = 15
```

So instead of finding only the maximum subarray sum, we also need the minimum subarray sum.

Finally,

```
Answer = max(maxSubarraySum, -minSubarraySum)
```

---

# Approach (Kadane Twice)

We maintain two running values.

### 1. Maximum Subarray Sum

Exactly Kadane's Algorithm.

```
maxEndingHere =
max(currentElement,
    maxEndingHere + currentElement)
```

Keep updating

```
maxSum
```

---

### 2. Minimum Subarray Sum

Same idea, but use `min` instead.

```
minEndingHere =
min(currentElement,
    minEndingHere + currentElement)
```

Keep updating

```
minSum
```

---

Finally,

```
answer = max(maxSum, abs(minSum))
```

# Algorithm

For every element

- Update maximum ending sum.
- Update minimum ending sum.
- Update global maximum.
- Update global minimum.

Finally return

```
max(maxSum,-minSum)
```

---

# Why Does This Work?

The maximum absolute subarray sum must be either

- the largest positive subarray
- or the smallest (most negative) subarray.

Kadane already gives the largest positive sum.

Running Kadane with `min()` instead of `max()` gives the smallest negative sum.

Thus checking both guarantees the optimal answer.

# Java Solution

```java
class Solution {
    public int maxAbsoluteSum(int[] nums) {

        int maxEnding = nums[0];
        int maxSum = nums[0];

        int minEnding = nums[0];
        int minSum = nums[0];

        for (int i = 1; i < nums.length; i++) {

            maxEnding = Math.max(nums[i], maxEnding + nums[i]);
            maxSum = Math.max(maxSum, maxEnding);

            minEnding = Math.min(nums[i], minEnding + nums[i]);
            minSum = Math.min(minSum, minEnding);
        }

        return Math.max(maxSum, -minSum);
    }
}
```

# Even Shorter Version (Using Prefix Sum)

Another elegant solution uses prefix sums.

Observation:

```
Subarray Sum = Prefix[j] - Prefix[i]
```

The largest absolute difference between two prefix sums gives the answer.

Maintain

- minimum prefix
- maximum prefix

Then

```
answer = maxPrefix - minPrefix
```

### Java

```java
class Solution {
    public int maxAbsoluteSum(int[] nums) {

        int prefix = 0;
        int maxPrefix = 0;
        int minPrefix = 0;

        for (int num : nums) {
            prefix += num;

            maxPrefix = Math.max(maxPrefix, prefix);
            minPrefix = Math.min(minPrefix, prefix);
        }

        return maxPrefix - minPrefix;
    }
}
```

# Comparison

| Method | Time | Space |
|---------|------|-------|
| Kadane (Max + Min) | O(n) | O(1) |
| Prefix Sum | O(n) | O(1) |

Both are optimal.

---

# Key Takeaways

- Absolute value means both positive and negative sums matter.
- Run Kadane once for maximum subarray.
- Run Kadane again for minimum subarray.
- Final answer is

```
max(maxSubarraySum, -minSubarraySum)
```

or equivalently use the Prefix Sum approach.

Both solutions run in **O(n)** time with **O(1)** extra space.
