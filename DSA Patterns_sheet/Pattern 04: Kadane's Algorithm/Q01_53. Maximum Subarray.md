# 53. Maximum Subarray (Kadane's Algorithm)

**LeetCode:** https://leetcode.com/problems/maximum-subarray/

## Problem
Given an integer array `nums`, find the contiguous subarray with the largest sum and return that sum.

## Java Solution

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int currSum = nums[0];
        int maxSum = nums[0];

        for (int i = 1; i < nums.length; i++) {
            currSum = Math.max(nums[i], currSum + nums[i]);
            maxSum = Math.max(maxSum, currSum);
        }

        return maxSum;
    }
}
```

## Explanation

`currSum` stores the maximum subarray sum **ending at the current index**.

At every element, we have two choices:

1. Start a new subarray from the current element.
2. Extend the previous subarray.

Formula:

```java
currSum = Math.max(nums[i], currSum + nums[i]);
```

Then update the global answer:

```java
maxSum = Math.max(maxSum, currSum);
```

## Dry Run

Input:

```text
[-2,1,-3,4,-1,2,1,-5,4]
```

| Index | Value | currSum | maxSum |
|------:|------:|--------:|-------:|
|0|-2|-2|-2|
|1|1|1|1|
|2|-3|-2|1|
|3|4|4|4|
|4|-1|3|4|
|5|2|5|5|
|6|1|6|6|
|7|-5|1|6|
|8|4|5|6|

Answer: **6**

Subarray: `[4, -1, 2, 1]`

## Time Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`

## Kadane's Algorithm Pattern

```java
currSum = Math.max(nums[i], currSum + nums[i]);
maxSum = Math.max(maxSum, currSum);
```
